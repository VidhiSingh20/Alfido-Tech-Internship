#  Alfido Tech Internship – Machine Learning Projects

This repository contains the Machine Learning projects completed during my internship at **Alfido Tech**. The projects cover data preprocessing, exploratory data analysis (EDA), feature engineering, model building, evaluation, and model deployment using Python and Scikit-learn.

##  Projects

###  Task 1 – Iris Flower Classification
- Predicted Iris flower species using classification models.
- **Algorithms:** Logistic Regression, Decision Tree, Random Forest
- **Tech Stack:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

###  Task 2 – House Price Prediction
- Built regression models to predict house prices.
- **Feature Engineering:** House Age, Sale Year, Sale Month, Total Square Feet, Log Transformation
- **Algorithms:** Random Forest Regressor, Gradient Boosting Regressor

###  Task 3 – Titanic Survival Prediction
- Predicted passenger survival using machine learning classification.
- **Feature Engineering:** Title Extraction, Family Size, IsAlone, Cabin Presence
- **Algorithms:** Logistic Regression, Random Forest, Gradient Boosting

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
